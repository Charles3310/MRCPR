# 心肺復甦術混合實境訓練系統
### CPR Mixed Reality Training System

> 結合 Mixed Reality（MR）、感測技術與 AI 影像辨識的 CPR 訓練輔助系統。

**開發期間：** 2025/09 – 2025/11

---

## 1. 專案介紹

現行 CPR 教學常受限於設備成本高昂、傳統訓練人偶體積龐大，以及缺乏即時操作回饋等問題，使學習者難以有效掌握正確的胸部按壓技巧。

本專案旨在結合混合實境（Mixed Reality, MR）與感測技術，開發一套低成本、輕量化且具備即時回饋功能的 CPR 訓練系統。

使用者配戴 Meta Quest 3，透過虛擬 CPR 人偶與實體感測裝置進行互動，並藉由感測數據分析按壓深度與頻率，提供即時訓練回饋。

### 專案目標

- 降低傳統 CPR 訓練設備的成本與空間需求。
- 透過 MR 技術提升訓練的互動性與臨場感。
- 整合實體感測裝置，即時取得胸部按壓數據。
- 提供按壓品質回饋，協助使用者建立正確的 CPR 操作技巧。
- 探索 AI 影像辨識於 CPR 姿勢判斷的應用。

## 3. 系統架構

本系統主要分為四個部分：實體感測裝置、資料傳輸、MR 視覺模擬，以及 AI 影像辨識。

### 系統資料流程

```text
┌─────────────────────────────┐
│       實體感測裝置           │
│                             │
│  GP2Y0A41SK0F 紅外線感測器   │
│             ↓               │
│           ESP32             │
│    感測資料讀取與處理        │
└──────────────┬──────────────┘
               │
          Wi-Fi / TCP
               │
               ↓
┌─────────────────────────────┐
│         Unity / C#          │
│                             │
│       資料接收與解析         │
│             ↓               │
│       按壓數據處理           │
│             ↓               │
│       訓練狀態判斷           │
└──────────────┬──────────────┘
               │
               ↓
┌─────────────────────────────┐
│       Meta Quest 3          │
│                             │
│       MR 虛擬人偶            │
│       即時操作介面           │
│       訓練結果與回饋         │
└─────────────────────────────┘
```

AI 影像辨識模組則另外使用第一人稱視角影像進行 CPR 手部姿勢分類，作為訓練姿勢判斷的延伸功能。

## 4. 核心功能與實作

### 4.1 MR 視覺模擬

使用 Meta Quest 3 建立混合實境 CPR 訓練環境，將虛擬 CPR 人偶與現實空間結合，讓使用者能夠透過實體裝置進行按壓操作。

**實作內容：**

- 使用 Unity 搭配 Meta XR SDK 建置混合實境環境。
- 匯入 3D 人體模型，進行虛擬人偶定位與互動設計。
- 結合現實空間與虛擬物件，建立 CPR 訓練場景。
- 設計虛擬操作介面，顯示按壓進度、評分指標及訓練資訊。
- 透過 Unity UI 呈現即時訓練數據與操作回饋。

### 4.2 實體感測裝置

使用 ESP32 搭配紅外線距離感測器，製作輕量化的實體按壓感測裝置，透過感測器量測按壓過程中的位移變化。

**實作內容：**

- 使用 GP2Y0A41SK0F 紅外線距離感測器讀取按壓位移。
- 透過 ESP32 進行感測資料讀取與初步雜訊處理。
- 建立 ESP32 Wi-Fi 熱點，提供 Unity 應用程式連線。
- 使用 TCP Socket 傳輸感測數據至 Unity。
- 將感測器距離變化轉換為按壓深度，作為訓練回饋依據。

### 4.3 感測資料處理與即時回饋

在 Unity 中使用 C# 接收 ESP32 傳輸的感測數據，進行資料處理與按壓狀態判斷，並將結果呈現在 MR 訓練介面。

**實作內容：**

- 建立 TCP Client，接收 ESP32 傳輸的感測資料。
- 將原始感測數值轉換為按壓深度。
- 設計按壓狀態管理機制，區分待機、準備及紀錄階段。
- 記錄按壓過程中的時間與深度數據。
- 根據按壓深度與頻率進行訓練表現分析。
- 使用 TextMeshPro 與圖表呈現即時數據及訓練結果。

### 4.4 AI 影像辨識

為提升 CPR 姿勢判斷能力，嘗試使用 YOLOv8 影像分類模型，透過 Meta Quest 3 第一人稱視角影像，辨識使用者雙手是否保持伸直。

**開發內容：**

- 使用 YOLOv8n-cls 建立 bent / straight 雙分類模型。
- 蒐集第一人稱視角影像，建立訓練資料集。
- 進行影像資料標註與前處理。
- 使用混淆矩陣分析模型分類表現。
- 探索透過 ONNX 將模型導入 Unity，進行裝置端推論。

## 5. 開發成果與技術挑戰

透過本專案，整合 Unity 混合實境開發、硬體感測與網路通訊，完成 CPR 訓練系統的核心互動流程。

**主要開發成果：**

- 建立 Meta Quest 3 混合實境 CPR 訓練環境。
- 完成 ESP32 與 Unity 之間的 Wi-Fi TCP 通訊。
- 實作感測數據接收、處理與按壓資訊紀錄。
- 建立按壓深度與頻率的訓練回饋機制。
- 嘗試導入 YOLOv8 進行 CPR 手部姿勢分類。

**開發過程中的技術挑戰：**

- MR 虛擬人偶與實體感測裝置的空間定位與互動整合。
- ESP32 與 Unity 之間的即時資料傳輸。
- 感測數據的雜訊處理與按壓狀態判斷。
- AI 模型訓練與 Unity 推論環境整合。
